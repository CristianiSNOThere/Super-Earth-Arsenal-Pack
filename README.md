# Super Earth Arsenal Pack

Three standalone Helldivers 2 mods, each published as its own release. Use only the mods you want.

**These mods are vibecoded:** they were made with AI coding assistance and iterative hands-on development.

## Mods

- [One True Flag — Adjustable Damage v0.9](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/releases/tag/one-true-flag-v0.9): configurable normal damage from 0–9999; defaults to 300 normal / 150 durable. Durable damage can be half or equal to normal. The package passed offline checks; confirm its chosen damage in a mission and check `FlagDamagePrototype.log`.
- [SAI — Focus Precision v0.4](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/releases/tag/sai-focus-precision-v0.4): 90 normal / 21 durable damage and 0.5 MRAD spread with the Focus Lens. In-game use confirmed.
- [AR-11 Arbitrator — Tuned v0.2](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/releases/tag/ar11-arbitrator-v0.2): 80 rifle damage, 65-round magazine, and 40 ergonomics with the default optic. In-game use confirmed, including against a Brood Commander.

## Install

Download the ZIP from the release for the mod you want, import it into Arsenal, and enable its option. Keep Bingus Shared Loader last at default priority. Use Arsenal's Purge and Deploy, then restart the game and wait aboard the ship for initialization. Each mod is independent.

The packages target Steam build 25480438. Flag Damage and AR-11 require Bingus Shared Loader v17 or newer. See each release and ZIP README for details, compatibility, and logs.
