# Super Earth Arsenal Pack

Four independent Helldivers 2 mods that tune weapon damage, accuracy, handling, or ammunition. Choose only the packages you want; each has its own ZIP and can be enabled separately.

**These mods are vibecoded:** they were made with AI coding assistance and iterative hands-on development.

## Mods

- [One True Flag — Adjustable Damage v0.9 release](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/releases/tag/one-true-flag-v0.9) · [Download ZIP](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/raw/refs/heads/main/mods/One-True-Flag-Damage-Adjustable-v0.9.zip): lets you set normal damage from 0 to 9999 and choose durable damage as either half or equal to normal damage. The default is 300 normal / 150 durable. Offline checks passed; the in-mission damage effect still needs confirmation. Check `FlagDamagePrototype.log` for the applied settings.
- [SAI — Focus Precision v0.4 release](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/releases/tag/sai-focus-precision-v0.4) · [Download ZIP](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/raw/refs/heads/main/mods/SAI-Focus-Precision-v0.4.zip): tunes the LAS-12 SAI for the Focus Lens, setting spread to 0.5 MRAD and damage to 90 normal / 21 durable. In-game use is confirmed.
- [AR-11 Arbitrator — Tuned v0.2 release](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/releases/tag/ar11-arbitrator-v0.2) · [Download ZIP](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/raw/refs/heads/main/mods/AR-11-Arbitrator-Tuned-v0.2.zip): sets rifle damage to 80, magazine capacity to 65 rounds, underbarrel spare ammunition to 30, and ergonomics to 40 with the default optic. In-game use is confirmed, including against a Brood Commander.
- [R/40-K Hot-Shot — Magazine Tuning v0.8 ZIP](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/raw/refs/heads/main/mods/R40-K-Hot-Shot-v0.8-Magazine-Tuning.zip): increases magazine capacity from 12 to 20 rounds and ergonomics from 30 to 45. Starting, resupply, and maximum magazine counts are five. It keeps the normal magazine reload system; it does not add heat or heatsinks. The user confirmed the tuning works in-game. This ZIP is committed to the repository but is not a separate GitHub Release.

## Install

Download the ZIP for each mod you want, import it into Arsenal, and enable that mod's option. Keep Bingus Shared Loader last at default priority. Use Arsenal's Purge and Deploy, then restart the game. Once aboard the ship, allow up to about a minute for the mods to initialize before testing them in a mission. You do not need to enable the other packages for a single mod to work.

The packages target Steam build 25480438. Flag Damage and AR-11 require Bingus Shared Loader v17 or newer. See each release and ZIP README for details, compatibility, and logs.
