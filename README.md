# Super Earth Arsenal Pack

A collection of 15 Helldivers 2 mods, each available as its own ZIP and option. For the full set in one package, see the [Super-Earth Arsenal Modpack](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Modpack). Choose either the individual ZIPs or the modpack ZIP; enabling both duplicates the same add-on resources.

Each weapon or sentry mod can be installed alone or alongside other mods. These packages require Bingus Shared Loader v15 or newer and Steam build 25480438. If an installed companion mod fails to initialize, the weapon and sentry mods do not apply their settings. See the [weapon and sentry mod index](mods/Weapon-Mods-README.md) for package details and compatibility notes.

## Install

1. Download the ZIP for each mod you want and import it into Arsenal.
2. Enable the mod or mods you want to use. Each package can be enabled separately.
3. Keep Bingus Shared Loader last at its default priority.
4. In Arsenal, run Purge and Deploy, then start Helldivers 2.
5. After loading onto the ship, allow up to about 2 minutes for the mods to initialize before use.

The packages target Steam build 25480438. Flag Damage and AR-11 require Bingus Shared Loader v17 or newer; Sterilizer, ARC-3, and the modpack require v18 or newer. Each weapon or sentry mod requires v15 or newer. See each release and ZIP README for details and compatibility.
