# Super Earth Arsenal Pack

Standalone Helldivers 2 weapon and damage mods. Use only the mods you want. The R/40-K Hot-Shot now has a confirmed magazine-tuning option: 20 rounds per magazine and 45 ergonomics.

**These mods are vibecoded:** they were made with AI coding assistance and iterative hands-on development.

## Mods

- [One True Flag — Adjustable Damage v0.9 release](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/releases/tag/one-true-flag-v0.9) · [Download ZIP](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/raw/refs/heads/main/mods/One-True-Flag-Damage-Adjustable-v0.9.zip): configurable normal damage from 0–9999; defaults to 300 normal / 150 durable. Durable damage can be half or equal to normal. The package passed offline checks; confirm its chosen damage in a mission and check `FlagDamagePrototype.log`.
- [SAI — Focus Precision v0.4 release](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/releases/tag/sai-focus-precision-v0.4) · [Download ZIP](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/raw/refs/heads/main/mods/SAI-Focus-Precision-v0.4.zip): 90 normal / 21 durable damage and 0.5 MRAD spread with the Focus Lens. In-game use confirmed.
- [AR-11 Arbitrator — Tuned v0.2 release](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/releases/tag/ar11-arbitrator-v0.2) · [Download ZIP](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/raw/refs/heads/main/mods/AR-11-Arbitrator-Tuned-v0.2.zip): 80 rifle damage, 65-round magazine, and 40 ergonomics with the default optic. In-game use confirmed, including against a Brood Commander.
- [R/40-K Hot-Shot — Magazine Tuning v0.8 ZIP](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/raw/refs/heads/main/mods/R40-K-Hot-Shot-v0.8-Magazine-Tuning.zip): 20 rounds per magazine, with five magazines starting, from resupply, and at maximum; ergonomics 45. Its in-game use is confirmed. It keeps the stock magazine and reload behavior; it does not add heat mechanics.

## Install

Download the ZIP for the mod you want, import it into Arsenal, and enable its option. Keep Bingus Shared Loader last at default priority. Use Arsenal's Purge and Deploy, then restart the game. After loading onto the ship, wait up to about a minute for the mods to initialize before entering a mission. Each mod is independent.

The packages target Steam build 25480438. Flag Damage and AR-11 require Bingus Shared Loader v17 or newer. See each release and ZIP README for details, compatibility, and logs.
