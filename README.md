# Super Earth Arsenal Pack

Four independent Helldivers 2 mods that tune weapon damage, accuracy, handling, or ammunition. Choose only the packages you want; each has its own ZIP and can be enabled separately.

**These mods are vibecoded:** they were made with AI coding assistance and iterative hands-on development.

## Mods

- [One True Flag — Adjustable Damage v0.9 release](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/releases/tag/one-true-flag-v0.9) · [Download ZIP](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/raw/refs/heads/main/mods/One-True-Flag-Damage-Adjustable-v0.9.zip): lets you tune how much damage the One True Flag deals, with separate control for ordinary and durable targets. Choose whether durable damage is half or equal to normal damage. In-mission behavior still needs confirmation.
- [SAI — Focus Precision v0.4 release](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/releases/tag/sai-focus-precision-v0.4) · [Download ZIP](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/raw/refs/heads/main/mods/SAI-Focus-Precision-v0.4.zip): a precision-focused LAS-12 SAI setup. The Focus Lens has a tighter shot spread, with damage tuned for the weapon. In-game use is confirmed.
- [AR-11 Arbitrator — Tuned v0.2 release](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/releases/tag/ar11-arbitrator-v0.2) · [Download ZIP](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/raw/refs/heads/main/mods/AR-11-Arbitrator-Tuned-v0.2.zip): makes the AR-11 a more capable rifle with a larger magazine, more ammunition for its underbarrel launcher, stronger rifle damage, and quicker handling. In-game use is confirmed, including against a Brood Commander.
- [R/40-K Hot-Shot — Magazine Tuning v0.8 ZIP](https://github.com/CristianiSNOThere/Super-Earth-Arsenal-Pack/raw/refs/heads/main/mods/R40-K-Hot-Shot-v0.8-Magazine-Tuning.zip): gives the R/40-K a 20-round magazine and improved handling while keeping its familiar magazine reload. It carries five magazines, and the user confirmed the changes work in-game. This ZIP is in the repository but is not a separate GitHub Release.

## Install

1. Download the ZIP for each mod you want and import it into Arsenal.
2. Enable the mod or mods you want to use. Each package works independently, so you can choose any combination.
3. Keep Bingus Shared Loader last at its default priority.
4. In Arsenal, run Purge and Deploy, then start Helldivers 2.
5. After loading onto the ship, allow up to about a minute for the mods to initialize before testing them in a mission.

The packages target Steam build 25480438. Flag Damage and AR-11 require Bingus Shared Loader v17 or newer. See each release and ZIP README for details, compatibility, and logs.
