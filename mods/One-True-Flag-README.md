# One True Flag

## Current gameplay changes

Configurable normal damage from 0 to 9999 using four digit selectors in Arsenal, defaulting to 300. Durable damage is half of normal (rounded down) or equal to normal, defaulting to 150.

## Controls and compatibility

Enable Apply configurable flag damage and choose Thousands, Hundreds, Tens, Ones, and the durable-damage option. Apply selection changes with Purge and Deploy and a game restart.

## Install

Import the ZIP into Arsenal and enable its option. Keep Bingus Shared Loader at its documented priority, Purge and Deploy, and restart Helldivers 2. Choose the individual packages or the modpack to avoid duplicate addon resources.

Requires Helldivers 2 Steam build 25480438 and Bingus Shared Loader v17 or newer.
